# SPHead-ITR

**Paper:** *SPHead-ITR: A Benchmark for Instance-Level Image–Text Retrieval of Shadow Puppet Headpieces with LLM-Generated Captions*

**Authors:** Guocheng Sun, Kejian Yu, Zhihao Ma, Yajun Wang, Le Jiang, and Yunzhi Wu

SPHead-ITR is a benchmark for instance-level image–text retrieval of shadow puppet headpieces. It contains 34,699 images paired with three English appearance captions per image across the Five-role and Supernatural subsets.

The dataset is available from the corresponding author upon request.

`download_shadow_puppetry.py` is the image-collection script for the Five-role categories.
